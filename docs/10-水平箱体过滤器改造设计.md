# 水平箱体过滤器改造设计

## 背景

当前仓库中的水平箱体识别已经不是最初那版“分位数聚类 + 严格水平边界”方案，而是切换到了**基于 MA5 平滑后的局部波峰/波谷回归边界**方案。

当前实现位置：

- 因子：`modules/factors/box_consolidation.py`
- 过滤器：`modules/filters/box_consolidation.py`

其中：

- `BoxConsolidationMatchFactor` 负责核心识别逻辑与诊断
- `BoxConsolidationFilter` 只是对该因子做一层 filter 包装

## 当前实现概览

当前工作区中的箱体识别逻辑核心特征如下：

1. 只看最近 40 个交易日的箱体形态；
2. 先对收盘价做 `MA5` 平滑，用于削弱单日尖刺噪声；
3. 在平滑序列上识别局部波峰和波谷；
4. 分别对波峰和波谷做线性回归，得到上沿和下沿；
5. 用首尾漂移比例限制边界倾斜度，而不是要求绝对水平；
6. 价格仍需位于箱体内，避免识别已经脱离箱体的走势；
7. 对外暴露诊断结果，可统计每只股票被哪一条规则筛掉。

## 识别规则

### 1. 输入窗口

- 箱体观察窗口：`40` 个交易日；
- 平滑窗口：`5` 个交易日；
- 因为 `MA5` 需要预热，所以实际最少需要 `44` 个收盘价样本：

```text
INPUT_WINDOW = BOX_WINDOW + SMOOTHING_WINDOW - 1 = 44
```

如果样本不足 44 天，直接判定为 `insufficient_history`。

### 2. 平滑处理

只对 `close` 使用简单移动平均：

```text
smoothed[i] = average(close[i:i+5])
```

平滑后的 40 点序列只用于识别波峰和波谷，不直接替代原始收盘价参与“最近是否仍在箱体内”的判断。

### 3. 局部波峰和波谷识别

当前实现使用 3 点局部极值窗口，即中心点需要同时满足：

- 波峰：大于左右各 1 个相邻点；
- 波谷：小于左右各 1 个相邻点。

对应参数：

- `EXTREMA_RADIUS = 1`
- `MIN_EXTREMA_COUNT = 2`

要求：

- 波峰至少 2 个；
- 波谷至少 2 个。

若不满足，分别记为：

- `insufficient_peaks`
- `insufficient_valleys`

### 4. 用线性回归构造上沿和下沿

对波峰点和波谷点分别做一元线性回归：

```text
upper(x) = upper_slope * x + upper_intercept
lower(x) = lower_slope * x + lower_intercept
```

其中：

- `x` 为平滑序列中的时间索引；
- `y` 为对应波峰或波谷价格。

### 5. 边界漂移约束

对上沿和下沿分别计算首尾漂移比例：

```text
drift_ratio = abs(line(39) - line(0)) / ((line(39) + line(0)) / 2)
```

当前阈值：

- `MAX_BOUNDARY_DRIFT_RATIO = 0.10`

失败原因分别为：

- `upper_boundary_drift_too_large`
- `lower_boundary_drift_too_large`

### 6. 箱体高度约束

在窗口中点 `19.5` 处计算箱体高度：

```text
height_ratio = (upper(19.5) - lower(19.5)) / lower(19.5)
```

当前阈值：

- `MIN_BOX_HEIGHT_RATIO = 0.10`
- `MAX_BOX_HEIGHT_RATIO = 0.30`

失败原因：

- `box_height_out_of_range`

### 7. 最近价格仍在箱体内

当前实现还要求：

- 最新收盘价在箱体上下沿之间；或者
- 最近 3 个交易日至少有 2 天收盘价位于箱体内。

对应参数：

- `RECENT_WINDOW = 3`
- `MIN_RECENT_INSIDE_COUNT = 2`

失败原因：

- `recent_prices_outside_box`

## 诊断能力

当前诊断能力来自 `BoxConsolidationMatchFactor.evaluate_closes(closes)` 实例方法。

典型调用方式：

```python
from modules.factors.box_consolidation import BoxConsolidationMatchFactor

factor = BoxConsolidationMatchFactor({})
result = factor.evaluate_closes(closes)
```

返回 `EvaluationResult`，包含：

- `matched`：是否命中；
- `first_failure_reason`：首个失败原因；
- `condition_results`：各条件是否通过；
- `details`：调试细节，如峰谷数量、边界漂移比例、箱体高度、最近在箱体内的天数等。

`BoxConsolidationFilter` 内部也是通过这个因子逻辑来做最终筛选。

## 当前参数

按当前实现，关键参数如下：

- `BOX_WINDOW = 40`
- `SMOOTHING_WINDOW = 5`
- `INPUT_WINDOW = 44`
- `EXTREMA_RADIUS = 1`
- `MIN_EXTREMA_COUNT = 2`
- `MAX_BOUNDARY_DRIFT_RATIO = 0.10`
- `MIN_BOX_HEIGHT_RATIO = 0.10`
- `MAX_BOX_HEIGHT_RATIO = 0.30`
- `RECENT_WINDOW = 3`
- `MIN_RECENT_INSIDE_COUNT = 2`
