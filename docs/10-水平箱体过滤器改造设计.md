# 10-水平箱体过滤器改造设计

## 背景

现有 `modules/filters/box_oscillation_gain.py` 主要基于：

- 最近 60 日局部高低点数量
- 高低点整体价差约束
- 高低点上下沿切换次数
- 最新一日涨幅 >= 2%

该实现更接近“箱体震荡 + 当日上涨”的粗筛逻辑，不能稳定识别**水平箱体**，也缺少对“近期仍在箱体内”的约束。

## 本次改造目标

保留现有 Filter 对外入口（类名与 `name` 不变，兼容现有调用），但内部逻辑改为只识别：

1. 最近 60 个交易日存在明显的上下沿往返震荡；
2. 上下沿应近似水平，而不是斜向通道；
3. 箱体高度处于合理范围内，避免把微小噪声或超宽波动当成箱体；
4. 同一天不能同时记为局部高点和局部低点；
5. 近期价格仍然停留在箱体内部。

## 识别规则

### 1. 局部高低点采样

沿用三日局部极值方法：

- 局部高点：`high[i] >= high[i-1] && high[i] >= high[i+1]`，且至少严格大于一边；
- 局部低点：`low[i] <= low[i-1] && low[i] <= low[i+1]`，且至少严格小于一边。

若同一天同时满足高点和低点条件，则**整根 K 线跳过**，避免长影线制造虚假的上下切换。

### 2. 用分位数构造稳定边界

不再用全部高点/低点的 `min-max` 直接定义箱体边界，而是使用分位数做稳健估计：

- 计算局部高点/低点价格的 `Q1 / Median / Q3`；
- 用 `Median` 作为边界中心；
- 用 `IQR = Q3 - Q1` 作为边界离散度；
- 用 `Median ± max(IQR, 最小带宽)` 形成稳定触达区间。

这样可以降低单个异常影线对箱体边界的干扰。

### 3. 边界水平性判断

对高点边界和低点边界分别做一元线性回归（价格对时间索引）：

- 计算边界回归线在首尾触点之间的漂移幅度；
- 以边界中心价归一化；
- 漂移比例不能超过阈值。

这一步用于排除缓慢上升/下降通道，只保留近似水平箱体。

### 4. 箱体高度约束

以边界中心价定义箱体高度：

`height_ratio = (upper_center - lower_center) / lower_center`

要求高度比例落在合理区间内：

- 不能过小：避免把细碎噪声识别成箱体；
- 不能过大：避免把宽幅震荡或趋势回撤通道识别成箱体。

### 5. 仍需存在上下沿往返震荡

保留“上下沿触达顺序至少交替 4 次”的约束，例如：

- `upper -> lower -> upper -> lower`
- `lower -> upper -> lower -> upper`

但触达判断使用新的稳健边界区间，而不是 `min-max`。

### 6. 近期仍在箱体内

对最近 5 个交易日的收盘价做约束：

- 最新收盘价必须在箱体上下边界之间；
- 最近 5 日至少 4 日收盘价在箱体内部。

这一步用于排除“曾经是箱体，但最近已经离开箱体”的走势。

## 参数建议

- `WINDOW_SIZE = 60`
- `MIN_EXTREMA_COUNT = 2`
- `MIN_ZONE_TOUCHES = 4`
- `BOUNDARY_SPREAD_LIMIT = 0.08`
- `BOUNDARY_DRIFT_LIMIT = 0.05`
- `MIN_BOX_HEIGHT_RATIO = 0.04`
- `MAX_BOX_HEIGHT_RATIO = 0.30`
- `RECENT_WINDOW = 5`
- `MIN_RECENT_INSIDE_COUNT = 4`

## 影响范围

- `modules/filters/box_oscillation_gain.py`
- `modules/test/test_research_filters.py`

## 非目标

- 本次不做箱体突破识别；
- 本次不引入成交量、换手率、布林带等额外约束；
- 本次不做多周期箱体识别或聚类分型扩展。
