# 11-沪深主板过滤器设计

## 背景

当前选股 Filter 主要基于行情行为做筛选，但缺少一个基础市场范围约束：

- 只保留沪深主板；
- 排除创业板；
- 排除科创板。

这类约束适合作为独立 Filter 叠加在其他技术形态 Filter 之前使用。

## 设计目标

新增一个独立 Filter：`main_board`。

职责仅限于：

- 保留沪深主板 A 股；
- 排除创业板（`300*.SZ`）；
- 排除科创板（`688*.SH`）。

## 识别规则

由于当前 `Filter` 接口只接收 `StockDailyData`，其中只有 `instrument_id` 和行情数据，
因此本次实现不依赖 `stock_info` 的额外板块字段，而是直接基于 `instrument_id` 的交易所后缀和证券代码前缀判断。

### 上海主板

保留以下代码前缀：

- `600*.SH`
- `601*.SH`
- `603*.SH`
- `605*.SH`

明确排除：

- `688*.SH`（科创板）

### 深圳主板

保留以下代码前缀：

- `000*.SZ`
- `001*.SZ`
- `002*.SZ`
- `003*.SZ`

明确排除：

- `300*.SZ`（创业板）

### 其他情况

以下情况统一排除：

- 代码格式非法；
- 非 `.SH` / `.SZ` 后缀；
- 不在上述主板前缀范围内的标的。

## 使用方式

可以作为前置 Filter 使用，例如：

1. 先 `MainBoardFilter()` 缩小股票池；
2. 再叠加换手率、箱体等行为型 Filter。

## 影响范围

- `modules/filters/main_board.py`
- `modules/test/test_research_filters.py`

## 非目标

本次不处理：

- 北交所；
- ST、退市整理、风险警示等附加标签；
- 基于 `stock_info` 表字段的更细颗粒度板块识别。
