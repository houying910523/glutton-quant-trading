# 饕餮文档索引

`饕餮` 是一个面向个人开发者、从零起步搭建的量化交易系统。

这批文档的目标不是直接教你“怎么赚钱”，而是先把系统应该长什么样、为什么要拆成这些模块、第一版应该先做什么讲清楚。对于当前仓库，文档先于代码，`docs/` 是唯一正式设计入口。

## 文档说明

- `01` 面向零基础，先建立术语和系统认知。
- `02` 是主架构文档，定义模块边界、数据流和 MVP 范围。
- `03` 把 A 股特有规则集中到市场适配层，避免污染通用架构。
- `04` 把系统从想法推进到可运行产品的实施顺序拆开。
- `05` 定义首版研究与回测底座真正需要的数据对象。
- `06` 给出数据接入、标准化和存储的完整落地方案。
- `07` 定义策略如何产出信号，以及回测引擎如何解释这些信号。
- `08` 总结已定决策、当前边界，以及下一个 agent 应继续完成的详细设计任务。
- `09` 把首版数据接入、标准化、批次管理、标准层存储和服务层切片设计补到可直接实现的粒度。

## 当前结论

- `饕餮` 的首版定位是个人可控、低频优先、只先完成研究和回测闭环。
- 主架构按通用量化系统设计，但示例和约束优先参考 A 股场景。
- 首版必须模块只保留：数据接入、数据标准化与存储、策略信号、回测引擎。
- 组合构建、风控、订单管理、账户状态、调度与监控统一延后到下一阶段。
